# Instrucciones del proyecto

Leer `PROJECT_PLAN.md` antes de realizar cambios. El alcance actual es exclusivamente
la Fase 2: autenticación y administración local, autorizada por el usuario después
de verificar la Fase 1. No crear módulos comerciales ni iniciar despliegues cloud.
Mantener TypeScript estricto, migraciones versionadas y secretos fuera del repositorio.
No modificar servicios cloud, desplegar, hacer commits ni publicar sin autorización.
Validar con `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build` y las
comprobaciones Docker descritas en README.md. Informar resultados reales y bloqueos.
